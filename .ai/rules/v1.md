# V1

## Validated DTO request boundary

Type-hint the endpoint's ValidatedDTO in controller actions and pass $dto->toArray() to the service.

## Dashboard resource controllers

Implement dashboard CRUD with multi-method resource controllers.

## Resolve CRUD identifiers through services

Accept scalar $...Id arguments in resource-controller actions and resolve records through the service and repository layer.

## Versioned service-repository CRUD architecture

Delegate synchronous business and persistence work to the matching versioned service, acquired with FeatureService::make().

## Explicit relationship loading

Declare response relationships in $this->relations and pass the list through service calls.
